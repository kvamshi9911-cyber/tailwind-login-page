# Tailwind CSS Login Page

A simple and responsive **Login Page** created using **HTML5** and **Tailwind CSS**. This project was built as part of my Tailwind CSS learning journey to practice utility classes and understand how to design modern user interfaces without writing custom CSS.

## 📌 Project Overview

This login page includes the basic components commonly found in authentication pages. The design is clean, responsive, and beginner-friendly, making it a great practice project for learning Tailwind CSS.

## ✨ Features

* Welcome heading
* User Name input field
* Email input field
* Password input field
* Remember Me checkbox
* Forgot Password link
* Login button
* Sign Up link
* Responsive login card layout
* Built entirely with Tailwind CSS utility classes

## 🛠️ Technologies Used

* HTML5
* Tailwind CSS (CDN)

## 📚 Tailwind CSS Concepts Practiced

* Flexbox
* Background Colors
* Text Colors
* Typography
* Margin and Padding
* Width Utilities
* Border Styling
* Rounded Corners
* Shadows
* Form Styling
* Button Styling
* Hover Effects
* Focus Effects
* Responsive Layout
